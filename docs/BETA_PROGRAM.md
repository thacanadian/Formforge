# FormForge Beta Program

FormForge v1.8.0 is being validated with a private beta group of 20+ testers.

## What the beta is for

The beta is intended to test real-world usability, reliability, onboarding, mobile behavior, privacy/security flows, and the usefulness of FormForge's training, nutrition, recovery, progress, and coaching features.

## What we track

- Tester count and activation
- Repeat usage / returning testers
- Feedback submissions
- Bugs reported and resolved
- Feature requests
- Product changes shipped from tester feedback
- Release/version used during testing

## Feedback workflow

1. Tester uses the current beta build.
2. Feedback is recorded as a bug, usability issue, feature request, or positive signal.
3. Reproducible issues are documented with steps and environment details when available.
4. Changes are prioritized by severity and user impact.
5. Shipped fixes and improvements are recorded in the changelog/release notes.

## Reporting rules

Public claims should use only verified metrics. Do not publish private tester information, health data, credentials, screenshots, or feedback without permission. Tester counts should describe actual participants, not downloads or hypothetical users.

## Current public metric

- 20+ beta testers

Additional metrics will be added only after they are measured and verified.
