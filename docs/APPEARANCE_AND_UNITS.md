# Appearance and Measurement Settings

Open **Appearance** from the left navigation or select the palette icon in the top bar. The page contains five presets—Forge, Midnight, Iron, Arctic, and Forest—and custom accent, background, surface, text, corner-radius, density, and navigation controls. Preferences are stored separately for each user.

Choose **Imperial** for pounds and inches or **Metric** for kilograms and centimeters. FormForge stores canonical body weights, goal weights, exercise loads, and heights in kilograms and centimeters, then converts values at the input/display boundary. Changing the preference does not rewrite or damage historical records. Small display differences may occur because of rounding.

Standard users default to focused navigation. They can select full navigation from this page. Administrators also see **Preview member view** in the top bar, which changes navigation presentation only; it does not remove administrator permissions or modify another user’s account.
