# Standard-User and Member Interface

A standard user sees a focused navigation by default: Dashboard, AI Coach, AI Agent, Workouts, Nutrition, Progress, Coaching Team, Appearance, and More. **More** contains Health + Plans, Habits, Community, Check-In, Marketplace, Mobile, Security, and Profile + Data, so simplifying the navigation does not remove any authorized feature.

Members may change Navigation to **Full** under Appearance. Administrators retain the full administration interface and can select **Preview member view** in the top bar to see the focused presentation. Preview mode is visual only: it does not alter role-based authorization, data access, or the logged-in account. Exit the preview from the same button.
