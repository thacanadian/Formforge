# FormForge Security and Breach Notice — Review Copy

## Security controls

FormForge uses HTTPS for hosted traffic, password hashing, secure sessions, CSRF controls, login throttling, encrypted secrets and progress photos, audit logging, and encrypted backups. The operator must protect Render, domain, app-store, email, source-control, and AI-provider accounts with multifactor authentication.

## User responsibilities

Users should use unique passwords, protect their devices, enable available two-factor authentication, revoke lost-device sessions, and never share recovery keys or API keys.

## Incident response

When unauthorized access is suspected, the operator should:

1. Contain access and rotate affected credentials.
2. Preserve logs and evidence.
3. Determine which people, records, and providers were affected.
4. Document decisions and corrective actions.
5. Notify users, regulators, providers, and law enforcement when required.
6. Review the FTC Health Breach Notification Rule when identifiable health information may have been exposed.
7. Apply Texas breach-notification requirements, including affected-person notice and Attorney General reporting when the statutory threshold is met.
