# FormForge Legal Pages

FormForge serves the public pages below from the running app:

- `/legal/terms`
- `/legal/privacy`
- `/legal/community`
- `/legal/subscription`
- `/legal/health-ai`
- `/legal/security`
- `/account-deletion`

The deployed pages insert the operator identity, contact details, minimum age, price, and governing-law wording from `FORMFORGE_*` environment variables. The Markdown files in this folder are review copies, not a separate source of truth. Keep the embedded pages and these copies aligned when policies change.

These are practical product templates, not individualized legal advice. Before a public paid launch, have a Texas attorney review the completed pages using the real operator name, address, support contacts, data flows, payment implementation, and business practices.
